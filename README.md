# Personal Mini-Toolkit

## What This Toolkit Does

This Personal Mini-Toolkit is a Python program with three useful tools. It includes a simple calculator, a to-do list, and a number checker. The program uses a menu so the user can choose a tool and return to the main menu when finished.

## Tools

1. Simple Calculator - Performs addition, subtraction, multiplication, and division.
2. To-Do List - Allows the user to add, view, and remove tasks.
3. Number Checker - Checks whether a number is even or odd.

## How to Run

1. Open the project folder in VS Code.
2. Open `toolkit.py`.
3. Open the VS Code terminal.
4. Run the program with:

`python toolkit.py`

## Reflection

The hardest part of this project was understanding how the menu loop connects all the tools together. The to-do list was also challenging because the list needed to change while the program was running. One bug I had to think carefully about was making sure the program did not crash when the user entered an invalid menu choice. I learned how to use lists with append and remove operations. I also practiced using if, elif, and else to make decisions. The project helped me understand how loops can keep a program running until the user chooses to quit. With one more week, I would add more tools and make the toolkit more interactive.
